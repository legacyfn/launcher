# Project Legacy Launcher v4.3.6

## Changes

- Added a refreshed Project Legacy desktop theme with lime and purple brand accents.
- Added a separate theme stylesheet loaded by the existing Tauri UI bridge.
- Preserved the existing launcher API and application behavior; this release focuses on the visual layer.

## Release validation

This is a release candidate. Run the Windows GitHub Actions workflow, install the signed test artifact, and verify the dashboard, Servers tab, Settings screen and existing launcher functionality before creating the `v4.3.6` release tag.
