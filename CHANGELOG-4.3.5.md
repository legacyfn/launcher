# Project Legacy Launcher v4.3.5

## Changes

- Fixed native Windows match-open notifications and made the notification preference persist reliably.
- Pauses launcher animations and background media while the launcher window is inactive, then resumes them when the launcher is focused again.
- Refreshed the launcher interface styling to better match the Project Legacy website.
- Added dedicated Solo, Duos and Squad artwork in the Servers tab.
- Fixed the asynchronous Tauri `open_link` command return type.

## Release validation

This changelog describes the changes prepared for v4.3.5. The release is not considered ready to publish until Windows CI, signed installer packaging and the manual Windows smoke tests in `RELEASE-READINESS.md` pass.
